# Sift 三栏布局最小接线

> 旧版说明：本文描述“素材 / 产出 / 对话”阶段的布局，当前主线已经改为“参考 / 文档 / 原生对话”。

日期：2026-09-14。

当前工作区配置为 `profile: sift` 且状态有效时，Client 保留原生 `main/conversation`，在它左侧组合“素材、产出”两栏，使页面右侧形成“素材｜产出｜原生对话”三栏；切换到缺少 Sift 配置的 default 工作区时，移除附加栏并恢复 DSH 原生页面。切换由当前 Session 与 Workspace 的原生关联驱动，异步返回会校验代次，旧工作区结果不能覆盖新选择。

素材栏已接入[旧版素材面板](旧版-素材面板.md)，支持 Markdown、PDF、DOCX 和网页预览；产出栏已接入 [旧版 Markdown 编辑器](旧版-Markdown-编辑器.md)，提供本地 Markdown 文件选择、正文编辑和原文件保存。对话栏直接使用当前原生 Session 的完整界面，包括消息、输入框、模型、权限和其他会话插件。由于 DSH 0.1.5-rc.2 没有公开的 Conversation 包装插槽，当前接线通过版本内稳定的 `[data-rightbar-col]` 布局锚点定位 center column，在它内部追加两个兄弟栏并用 CSS Grid 将原生 Conversation 排到第三栏；没有复制或伪造聊天界面。升级 DSH 时必须把这处 DOM 契约列入兼容性验证。

## 手工验证

1. 运行 `pnpm dev:setup`、`pnpm dev:workspace-profile` 和 `pnpm dev`。
2. 打开终端打印的完整本地地址。
3. 打开 sift 工作区中的会话，右侧应切换为“素材｜产出｜原生对话”三栏，并可继续使用原输入框。
4. 在 default 工作区中新建或打开会话，右侧应恢复原生 DSH 对话页面。
5. 往返切换，确认布局始终跟随当前会话所属工作区。

## 尺寸与折叠

两条纵向分隔线支持指针拖拽，三栏最小宽度依次为 220、320、360 像素。素材、产出和原生对话各有折叠按钮，折叠后保留 44 像素恢复入口；相邻栏折叠时对应分隔线暂停拖动。容器与各栏均由 `ResizeObserver` 观察，窗口或面板尺寸变化后会重新约束宽度，并触发原生界面重排。

布局宽度和折叠状态使用 `dsh-sift:layout:<workspaceId>` 键按工作区保存在浏览器 `localStorage`，刷新页面后恢复。当前配置属于 Web 客户端偏好，不写入工作区 `.sift/config.json`；后续需要跨浏览器或跨设备同步时，再增加 Host 持久化接口。

三栏顶部使用一个多选标签组控制显示状态。选中的“素材”“产出”“对话”显示对应栏目，再次点击取消选择并隐藏；栏目隐藏后不保留窄栏或竖排标题。三栏可以全部取消，此时仍保留标签组。“重置”会重新全选三栏，并尽量保留此前拖动的宽度。分隔线视觉宽度为 1px，拖拽热区保持 6px。

后续若 DSH 提供由 `main.conversation` 所有者导出的包装插槽，应把这段 DOM 接线迁移到公开契约，以降低版本升级风险。
