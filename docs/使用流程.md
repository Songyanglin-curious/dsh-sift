# 当前使用流程

Sift 不再要求创建专用工作区，也不接管 DSH 布局。以下流程适用于任意普通 DSH 工作区。

## 1. 打开文章

使用 DSH 原生“工作区文件”打开 Markdown 或文本文件。文章继续显示在 DSH 右侧栏中，可以使用原生标签页、分栏和外部编辑器能力。

## 2. 打开当前文章的参考

文件工具栏中，“Markdown”打开方式前会出现书本形状的“参考”图标。点击后，从右侧展开参考抽屉。抽屉标题显示当前文件名，并明确标注“仅关联当前文章”。

文章路径是关系主键：切换文件后再打开参考，会读取另一组关系；不需要为文章创建 Sift Workspace、Document 或 Output。

## 3. 添加和整理参考

- 点击新建入口创建 Reference。
- 点击添加已有入口，把已有 Reference 关联到当前文章。
- 在卡片 Reference 中直接粘贴剪贴板内容并预览。
- 卡片支持编辑、删除、排序和来源打开。
- 移除关联不会删除原文件；永久删除仍需单独确认。

## 4. 使用会话参考

可以导入 ChatGPT 或 DeepSeek 导出的 Markdown。Sift 按 Q/A Group 展示，并允许以主题或某个 Q/A 为锚点分析 User Turn 相关性。分析只帮助定位，不自动生成文章内容。

## 5. 使用批注

批注由独立的 `@songyanglin/dsh-annotations` 提供：

1. 在文章、Reference 卡片或对话中选择文字。
2. 选区附近自动浮出“批注”菜单。
3. 写下修改意见并加入本轮。
4. 批注作为 DSH 原生引用进入当前输入框。
5. 使用当前 Agent 和 DSH 文件工具完成修改。

Sift 不维护第二套会话、Document 编辑器或 AI 写回协议。
