# 当前使用流程

本文只描述当前已经接入界面的操作。尚未完成的 Source Drawer 和 AI 提取 Reference 见[路线图](路线图.md)，不作为现成功能写入本流程。

## 1. 创建 Sift 工作区

1. 在 DSH 侧边栏点击添加工作区。
2. 选择 `sift` 类型。
3. 选择或创建一个本地目录。
4. 进入工作区后，主区域显示“参考｜文档｜原生对话”三栏。

选择 `default` 的工作区继续使用 DSH 原生界面，不启用 Sift 工作台。

## 2. 建立 Reference 工作集

Reference 是当前思考真正要使用的内容。工作区启动时不会自动创建或打开 Reference，需要用户明确操作。

- 点击 `＋` 新建 Reference。
- 点击“列表＋”将已有 Reference 加入当前工作集。
- 在打开的 Reference 中按 `Ctrl+V`，把剪贴板内容转换为卡片。
- 也可以点击卡片区底部的 `＋` 读取剪贴板。
- 卡片支持编辑、删除和拖动排序。
- 卡片可以记录网页或本机文件来源；来源图标可打开对应地址。
- 焦点位于 Reference 面板时，使用 `Ctrl+Z` / `Ctrl+Y` 撤销或重做卡片操作。

没有活动 Document 时，Reference 处于自由工作模式。关闭 Tab 只从当前工作集移除，不删除物理 Reference；永久删除必须使用独立垃圾桶并确认。

## 3. 创建或打开 Document

中间栏的 Document 是准备长期保留的 Markdown 产出。

- 点击 `＋` 新建 Markdown，可输入文件名并选择保存目录。
- 点击“列表＋”添加已有 `.md` 文件。
- 点击 Tab 切换 Document，双击 Tab 修改显示标题。
- 中栏使用 DSH 原生 Markdown 视图只读展示正文。
- 点击“用外部编辑器打开”可在 VS Code 或系统默认程序中修改文件。
- 点击“同步”可立即从磁盘重新读取正文；切换 Document 或窗口重新获得焦点时也会自动检查。
- “移除”会解除工作区登记并保留原文件。
- 垃圾桶会在确认后永久删除 Markdown 文件。

新建 Document 会继承创建前当前可见的 References。添加已有 Document 只在它从未建立关系时初始化，不覆盖已经存在的关系或明确的空关系。

## 4. 维护 Document 与 References

打开 Document 后，左侧只显示与它关联的 References：

1. 切换到目标 Document。
2. 点击 Document 工具栏中的“编辑关联参考”。
3. 勾选或取消当前 Document 使用的 References。
4. 保存后，左侧立即更新。

有活动 Document 时，新建或添加已有 Reference 会明确写入当前 Document 的关系。切换 Document 只读取关系，不会修改关系。

需要始终区分：

```text
创建文件 != 打开文件
打开文件 != 建立关联
切换文件 != 修改关联
关闭 Tab != 删除物理文件
```

## 5. 使用“本轮批注”与 AI 对话

1. 在 Reference 卡片正文或 Document 正文中选中文字。
2. 点击选区旁的“＋ 批注”。
3. 写下对这段内容的判断、问题或修改意图。
4. 点击“加入本轮”。
5. 批注以引用形式进入 DSH 原生输入框，并显示在输入框上方。
6. 可以继续编辑、移除批注，或者补充本轮问题。
7. 最后使用 DSH 原生发送按钮发送。

当前“本轮批注”只服务于本轮原生会话，不是长期批注历史。输入时 `Enter` 加入本轮，`Shift+Enter` 换行，`Esc` 取消。AI 只能通过 `sift_update_current_document` 修改当前 Document；修改成功后中栏从磁盘同步，不要求先完成逐行 Diff 审批。

## 6. 推荐的日常循环

```text
粘贴和整理当前材料
    ↓
形成少量 Reference 卡片
    ↓
打开或创建 Document
    ↓
只关联当前真正需要的 References
    ↓
阅读、对比并写下本轮问题
    ↓
在 DSH 原生会话中与 AI 分析
    ↓
用 VS Code 人工修改，或让 AI 修改当前 Document
    ↓
回到 Sift 同步查看 Markdown
    ↓
继续补充 Reference，进入下一轮
```
