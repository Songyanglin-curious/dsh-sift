# 当前使用流程

Sift 不再要求创建专用工作区，也不接管 DSH 布局。以下流程适用于任意普通 DSH 工作区。

## 1. 打开文章

使用 DSH 原生“工作区文件”打开 Markdown 或文本文件。文章继续显示在 DSH 右侧栏中，可以使用原生标签页、分栏和外部编辑器能力。

## 2. 打开当前文章的参考

文件工具栏中，“Markdown”打开方式前会出现书本形状的“参考”图标。点击后，文件预览会自然收窄，右侧并排展开参考栏；它不覆盖正文。参考栏标题显示当前文件名，并明确标注“仅关联当前文章”。关闭后，文件预览恢复全宽。

参考栏的现场按文件 Tab 分开保存。某篇文章打开参考后，切到另一文件不会把参考栏带过去；再次切回原文章时，参考栏仍保持打开，并恢复切走前看到的材料、折叠状态、草稿和阅读位置。只有显式点击关闭，才会结束这篇文章的参考现场。

文章路径是关系主键：切换文件后再打开参考，会读取另一组关系；不需要为文章创建 Sift Workspace、Document 或 Output。

## 3. 添加和整理参考

空状态直接提供“粘贴剪贴板内容”“添加已有材料”和“导入会话”。不需要先创建 Reference：首次粘贴时，Sift 会自动创建内部存储并关联当前文章。

有内容后，顶部只保留“添加参考”和“⋯”：

- “添加参考”包含粘贴剪贴板、添加已有材料和导入会话。
- “⋯”包含当前材料的重命名和删除等低频管理动作。
- 卡片自身负责编辑、移除、排序和打开来源。
- 旧数据中一篇文章关联多份材料时，用名称选择器切换；不恢复旧版标签栏和五图标工具条。

Reference 文件仍作为兼容存储存在，但不再要求用户先管理容器再添加内容。

## 4. 使用会话参考

可以导入 ChatGPT 或 DeepSeek 导出的 Markdown。Sift 按 Q/A Group 展示，并允许以主题或某个 Q/A 为锚点分析 User Turn 相关性。分析只帮助定位，不自动生成文章内容。

## 5. 使用批注

批注由独立的 `@songyanglin/dsh-annotations` 提供：

1. 在文章、Reference 卡片或对话中选择文字。
2. 选区附近自动浮出“批注”菜单。
3. 写下修改意见并加入本轮。
4. 批注作为 DSH 原生引用进入当前输入框。
5. 使用当前 Agent 和 DSH 文件工具完成修改。

Sift 不维护第二套会话、Document 编辑器或 AI 写回协议。
