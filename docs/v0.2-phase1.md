# v0.2 Phase 1：骨架（Workspace Profile + 三栏 + Untitled Document）

日期：2026-09-15。对应实施文档 §45。

目标：实现 Sift Workspace Profile、三栏布局、dsh-adapter、Untitled Document。此时 Reference 为空，Document 可编辑，Session 仍是原生对话。验收：**Default Workspace 不受影响**。

结论：四项都已完成，Default Workspace 的行为在测试里被直接钉住（`tests/sift-layout-wiring.test.ts`）。

## 1. dsh-adapter：DOM 假设集中

实施文档 §7 要求所有 DSH DOM 假设集中、禁止业务组件自己 `document.querySelector`。本轮把原来堆在 `index.tsx` 里的接线拆成三个文件：

| 文件 | 职责 |
| --- | --- |
| `dsh-adapter/selectors.ts` | 全部 DOM 锚点与 data-* 标记；找不到锚点时返回 null |
| `dsh-adapter/layout.ts` | 三栏布局引擎：网格、分隔线、宽度与折叠、工具栏、偏好持久化 |
| `dsh-adapter/layout.css` | 布局样式（从 `index.tsx` 里 4704 字符的内联字符串提取并格式化） |
| `dsh-adapter/workspace-entry.ts` | 当前工作区推导、Profile 闸门、世代守卫、偏好键 |
| `dsh-adapter/input-trigger.ts` | Phase 0 已建立的 `@` 触发源契约 |

`index.tsx` 从 342 行降到约 250 行，且不再出现任何 `document.querySelector`。

DOM 契约仍然只有一条：0.1.5-rc.2 的 `[data-rightbar-col]` 前一个兄弟节点即 center column。锚点不存在时**放弃启用三栏并输出明确错误**，不再继续重排页面（§7.2），这条有测试覆盖。

## 2. 三栏：参考 | 文档 | 原生对话

左栏换成 Reference Board（`reference/board.ts`），中栏是 Document 编辑器，右栏保持 DSH 原生对话节点原地不动，只靠 CSS Grid 排到第三栏。

- 工具栏标签由「素材 / 产出 / 对话」改为「参考 / 文档 / 对话」。
- 栏位 id 由 `materials` 改为 `reference`，CSS 与 TS 同步。
- 布局引擎不再认识任何具体栏内容：调用方传 `columns` 与 `mount`，Phase 2/4 换内容不需要动布局代码。

**Material 面板退出主链**：`materials-panel.ts` / `material-preview.ts` 不再被 `index.tsx` 引用，文件按 §41 暂时保留、到 Phase 10 删除。直接后果是客户端产物从 10.4 MB 降到 7.6 MB（PDF.js 与 docx-preview 随预览组件一起离开客户端包）。预览能力会在 Source/Reference 阶段以新的形态回来。

## 3. Untitled Document

实施文档 §28 要求：创建 Sift Workspace 时打开一个 `path = null` 的 Untitled Document，用户可以先写，**首次保存时才创建 Markdown**。

宿主侧新增 `host/document/store.ts`：

- `.sift/documents.json` 登记表（`schemaVersion` + documents 数组）。
- `saveDocument`：`path` 为 null 时由 Host 分配 `notes/<标题>.md`（同名自动另取 `notes/<标题> 2.md`），写正文、登记记录。
- 路径校验 `resolveInsideWorkspace`：拒绝 `..` 逃逸与越界绝对路径；与 `materials.ts` 的 `workspaceFile` 不同，它**不要求目标已存在**（首次保存要创建新文件）。
- 写入沿用已验证的模式：按工作区串行、临时文件 + rename 原子替换；登记表损坏时抛错而不是静默覆盖。
- 移除 Document 只解除登记，**不删磁盘文件**（§30）。

客户端 `document/store.ts` 放可单测的状态规则（`isUntitled` / `canAutosave` / `markSaved` / `applyEdit`），`document-editor.ts` 保留原有的编辑能力（Milkdown Crepe、脏标记、防抖自动保存、Ctrl+S、外部修改检测、beforeunload 保护），只把持久化目标从浏览器文件句柄改成工作区文件。

两条刻意的行为：

- **未落盘的 Document 不自动保存**。首次落盘必须是显式动作（保存按钮或 Ctrl+S），这样用户有机会先命名；落盘之后恢复自动保存。
- **未保存的编辑按工作区缓存在内存里**，切走再切回来能看到；重新挂载同一个工作区时不会重新读盘覆盖草稿。

## 4. 本轮踩到的三个真问题

1. **`toggleAttribute('data-chatCollapsed')` 永远不会匹配 CSS**。HTML 会把属性名小写化，`dataset.siftPanelToggle` 写出的属性是 `data-sift-panel-toggle`，而查询时用 `[data-siftPanelToggle]` 一个都匹配不到 —— 表现是工具栏按钮的 `aria-pressed` 全是 null。现在 data-* 键与属性名分别定义在 `SIFT_DATA` 与 `SIFT_ATTR`，并在注释里写明区别。
2. **少画了一条分隔线**。第一版只在前两栏之间加分隔线，漏掉了 Document 与原生对话之间那条。
3. **卸载不是幂等的**，而且某一栏清理抛错会让页面停在半重排状态。现在清理有幂等标志，且每个栏内容的清理单独 try/catch。

前两个是布局测试直接抓出来的，第三个是写完测试后修正的。
