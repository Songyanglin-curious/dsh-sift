# 路线图

## 当前基线

- Sift 已取消专用工作区类型和三栏工作台。
- DSH 原生文件预览是文章阅读入口。
- 每篇文章按文件路径关联自己的 References。
- Reference 支持剪贴板卡片和长会话相关性定位。
- 通用批注已拆分到 `@songyanglin/dsh-annotations`。

## 下一步

1. 在真实使用中收紧参考抽屉的尺寸、空状态和切换手感。
2. 让 Reference 通过 DSH 正式引用通道进入当前会话，避免隐式 Prompt。
3. 验证 URL、文件和剪贴板来源进入 Reference 的最短路径。
4. 清理仅为旧三栏实现保留的兼容代码和历史存储接口。

## 不做

- 不创建 Sift 工作区类型。
- 不实现 Document / Output 区域。
- 不重复实现 DSH 文件浏览、分栏、Markdown 查看或会话。
- 不建设全局知识库、知识图谱和复杂项目管理系统。
