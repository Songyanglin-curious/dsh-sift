# 产出栏 Markdown 编辑器

产出栏使用 `@milkdown/crepe` 7.22.1 提供所见即所得编辑，复用标题、列表、表格、代码块、链接、浮动工具栏和斜杠菜单。当前关闭公式功能，未启用 Crepe 内置 AI。

## 本地文件

进入产出栏后点击顶部文件位置入口，通过系统文件选择框打开 `.md` 或 `.markdown` 文件。使用浏览器 File System Access API 获取用户选择的文件句柄，不上传文件、不将正文保存到 localStorage。文件不限定在工作区目录内。

顶部仅显示可点击切换的文件名，不提供独立保存按钮。正文变更后延迟 400ms 自动写回原文件；连续输入合并写入，保存过程中产生的新修改顺序补写。正常保存完成后不显示额外状态文字，仅在等待、保存中或失败时提示。Ctrl/Cmd+S 仍可立即触发保存。保存前比较磁盘内容与打开时的内容，发现外部修改就停止保存并提示，用户可复制当前改动后重新打开文件。此检查不能排除检查之后其他进程同时写入的极短竞争窗口。

当前页面内按工作区保留文件句柄和未保存编辑；切换工作区时立即提交尚未保存的输入。刷新或关闭页面时，存在未保存内容会触发浏览器离开提醒。重新打开页面后需要重新选择文件。切换文件前先完成当前文件保存；保存失败时保留当前文件及改动。打开文件时申请写入权限，以便后续自动保存。

需要支持 File System Access API 的浏览器和安全上下文，例如 Chrome/Edge 中的 localhost 或 HTTPS。浏览器首次写入可能请求文件权限；不支持该 API 时显示说明。旧版本的浏览器草稿未删除，但新界面不再读取它。

本地相对图片资源解析、工作区文件列表和 AI 修改确认仍未接入。

## 构建与验证

Crepe 官方 common/classic 样式由 esbuild 打包为字符串，与客户端脚本一起注入。TypeScript 使用 Bundler 模块解析兼容 Crepe 声明。

自动化覆盖文件选择空态、自动写回原文件、外部修改阻止覆盖，以及工作区切换立即保存。类型检查和构建通过。

真实浏览器仍需验证系统文件选择框、写入权限、中文输入和实际磁盘保存；此前浏览器工具访问本地服务返回 `ERR_BLOCKED_BY_CLIENT`。
