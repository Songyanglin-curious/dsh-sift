# 当前验收说明

Sift 现在是“当前文章参考”插件，不再提供独立工作区类型、Document 区域或三栏工作台。验收以 DSH 原生文件浏览为主流程，并分别检查自动测试和真实浏览器行为。

## 自动检查

```powershell
pnpm check
pnpm test
pnpm build
pnpm verify:package
git diff --check
```

自动测试至少覆盖：

- Client 只注册当前文章参考入口，不再注册工作区类型和三栏布局。
- 参考入口能放到原生打开方式菜单之前，卸载后恢复原界面。
- 当前文章绝对路径可作为关系键，空值、控制字符和异常长度会被拒绝。
- Reference 创建、保存、删除、损坏数据保护和关系清理。
- 剪贴板卡片的添加、编辑、删除、排序与来源保留。
- ChatGPT / DeepSeek 会话导入、User Turn 解析和关联分析。
- Sift 设置、模型选择与思考强度持久化。
- 独立 Annotations 适配存在，但 Sift 不复制批注实现。

## 真实浏览器主流程

1. 启动装有 Sift 与 Annotations 的隔离 DSH Profile。
2. 打开普通工作区中的 Markdown 或文本文件。
3. 确认没有 Sift 工作区类型，也没有“参考 / 文档 / 对话”三栏。
4. 确认文件工具栏中“参考”图标紧邻并位于 Markdown 打开方式之前。
5. 点击图标，确认文件预览被自然压缩，右侧并排出现“参考 · 文件名”，并标明“仅关联当前文章”。参考栏不能覆盖正文。
6. 添加或新建 Reference，粘贴文本、网页内容与文件来源，确认预览、编辑和删除正常。
7. 导入一场会话，运行主题或锚点关联分析，确认候选位置可以定位。
8. 切换到另一篇文章，确认参考关系随文章路径切换，且不会隐式改写关系。
9. 刷新页面并重新打开参考栏，确认关系和内容可以恢复。
10. 关闭参考栏，确认正文恢复全宽，DSH 原生文件浏览、分栏、外部打开和会话不受影响。

## 批注协作验收

批注属于独立的 `@songyanglin/dsh-annotations`，不属于 Sift。本项目只验收二者协作：

1. 在 DSH 原生 Markdown / 文本预览中选中文字，选择菜单应自动浮出“批注”。
2. 点击后填写指令，原文定位与批注内容应进入当前原生会话。
3. Reference 卡片和导入会话中的选区也应走同一批注能力。
4. 卸载或停用 Sift 后，普通文件和对话中的批注仍可单独使用。

## 当前不应报告为已通过

- Sift 直接修改文章正文；正文修改继续由 DSH、外部编辑器或其他 Agent 能力承担。
- 自动把全部工作区材料变成文章参考；关联必须以当前文章为边界，由用户明确添加。
- 长期成本、跨批次分析漂移和两周真实使用体验；这些仍需使用期验证。
