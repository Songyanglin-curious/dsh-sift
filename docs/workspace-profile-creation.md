# 创建工作区时选择类型

Sift 接管侧边栏原有的“添加工作区”入口，并在目录选择前显示类型选择框：

- `default`：使用原生单栏对话界面。
- `sift`：启用素材、产出、对话三栏界面。

确认类型后，客户端依次调用 DSH 原生目录选择、原生工作区创建、Sift 类型写入和原生工作区打开。类型持久化在工作区的 `.sift/config.json` 中；缺少配置的历史工作区仍按 `default` 处理。

## 手工验收

1. 运行 `pnpm dev` 并打开终端输出的网址。
2. 点击侧边栏“工作区”标题右侧的添加按钮。
3. 确认弹窗同时显示 `default` 和 `sift`，选择 `sift` 后点击“选择目录并创建”。
4. 选择一个测试目录，确认工作区被打开且显示三栏界面。
5. 检查测试目录下 `.sift/config.json` 的 `profile` 为 `sift`。
6. 再创建一个 `default` 工作区，确认它保持原生界面，并在重启后维持该类型。

DSH 0.1.5-rc.2 没有为原生创建请求提供类型字段，也没有单独的“添加工作区按钮”扩展槽。因此当前实现复用公开的 `workspaces.create`、`uiWorkspace.pickDirectory` 和 `uiWorkspace.openWorkspace` 服务，并只替换该按钮的浏览器入口。
